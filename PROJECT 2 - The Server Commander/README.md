**# Project 2 - The Server Commander**



**## Project Overview**



**This project demonstrates deploying a custom website on an AWS EC2 instance using Nginx. The website was made publicly accessible through the EC2 Public IPv4 address.**



**## What I Built**



**- Created and configured an AWS EC2 instance**

**- Connected to the server using SSH**

**- Installed and configured Nginx**

**- Created a custom website using HTML and CSS**

**- Configured Security Group rules for SSH and HTTP access**

**- Deployed the website on the EC2 server**

**- Made the website publicly accessible**



**## Technologies Used**



**- AWS EC2**

**- Amazon Linux 2023**

**- Nginx**

**- Linux**

**- SSH**

**- HTML**

**- CSS**
